# 🎮 Bootcamp Hi Rappy — Pokédex

Projeto desenvolvido durante minha jornada de estudos em **Front-End**, como parte do **Bootcamp Hi Rappy** em parceria com a **DIO**.

A aplicação consiste em uma **Pokédex interativa**, desenvolvida com **HTML, CSS e JavaScript**, utilizando a **PokéAPI** para buscar e exibir informações dos Pokémon.

## 📌 Sobre o projeto

O projeto foi desenvolvido a partir de um desafio prático do Bootcamp, com o objetivo de colocar em prática conceitos de desenvolvimento Front-End e consumo de APIs.

### Principais conceitos praticados:

* JavaScript e manipulação do DOM;
* Requisições HTTP e `fetch()`;
* Promises e `async/await`;
* Consumo e tratamento de APIs;
* Dados em JSON;
* Responsividade;
* UI/UX;
* Git e GitHub.

## 🌐 PokéAPI

A aplicação utiliza a [PokéAPI](https://pokeapi.co/) para obter informações como nome, número, tipos, habilidades, status, imagens e evoluções dos Pokémon.

```text
https://pokeapi.co/api/v2/pokemon/{pokemon}
```

## 🧬 Evoluções

O projeto também trabalha com a consulta da **cadeia evolutiva** dos Pokémon, utilizando diferentes endpoints da API e praticando múltiplas requisições assíncronas.

## 👨‍💻 Sobre o projeto

Este projeto representa uma etapa da minha evolução como **UI/UX Designer e Front-End Developer**, unindo conhecimentos de design e desenvolvimento web.
